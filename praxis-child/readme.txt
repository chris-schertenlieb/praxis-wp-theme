Starter child theme for Praxis.

== Description ==

Override anything from the parent theme by adding a file with the same path:

* theme.json  - merged on top of the parent's theme.json
* templates/  - full-page templates (e.g. templates/single.html)
* parts/      - template parts (e.g. parts/header.html)
* patterns/   - additional block patterns
* styles/     - style variations

Requires the Praxis parent theme to be installed.
