An open source block theme built on Gutenberg with custom blocks.

== Description ==

Praxis is a Full Site Editing theme. Layout, templates and styles are managed in the Site Editor, and the theme ships a set of custom blocks under the "Praxis" inserter category.

== Development ==

Custom blocks are in src/blocks and must be compiled before use:

    npm install
    npm run build
